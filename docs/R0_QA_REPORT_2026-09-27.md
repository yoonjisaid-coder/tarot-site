## 접근성·검색·성능 점검

- 기존 버튼 이름, 선택 상태, modal title/description, Escape, 포커스 유지 동작을 확인했다. 화면 낭독기 실기기/200% zoom/전체 색 대비 감사는 미수행이다.
- 클라이언트 언어 수정은 완료했지만 초기 SSR의 `<html lang="en">`는 그대로다. KO SSR 언어 및 언어별 metadata는 후속 검토 대상이다.
- title/description과 카드 페이지 경로는 존재한다. canonical/hreflang/sitemap/robots 파일 및 사전에서 개별 상세 경로로 가는 crawlable 링크가 부재한다. 공개 도메인·색인 정책 결정 후 R1에서 정리한다. 현재 비공개 상태의 검색 유입 KPI는 미측정이다.
- 최종 client JS 전체 산출물 15개 합계 594,691 bytes, 개별 gzip 합계 190,424 bytes. 전체 chunk 합계이며 첫 페이지 네트워크 전송량이 아니다. 정적 public 자산 약 7.4MB, 사전 이미지는 lazy load. 새 의존성 없음.
- 실제 배포 TTFB/LCP/INP/CLS 및 저속 모바일 성능은 미측정이다. 빌드 성공을 성능 합격으로 대체하지 않는다.
